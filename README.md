# Mobile Sales Data Analysis

## Project Overview
This project analyzes mobile sales data to identify sales trends, customer behavior, and overall business performance.

## Tools & Technologies
- Python
- Pandas
- SQL
- Power BI
- Excel

## Key Analysis
- Data cleaning and preprocessing
- Sales and revenue analysis
- Product and brand performance analysis
- Customer and regional insights
- Interactive Power BI dashboard

## Key Insights
The analysis helps identify top-performing mobile brands, sales trends, revenue patterns, and other factors affecting business performance.

## Dashboard
An interactive Power BI dashboard was created to visualize important sales KPIs and insights.
